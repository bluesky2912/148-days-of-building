# 💻 Matrix Terminal

### 🚀 Day 001 of my **148 Days of Code** Challenge

An interactive Matrix-inspired terminal built with **HTML**, **CSS**, and **JavaScript**.

Experience a futuristic hacker-style interface with animated Matrix rain, a boot sequence, interactive terminal commands, themes, and hidden easter eggs.
